Run the real system

GitHub Codespaces starts a cloud machine with PHP 8.3 and MySQL 8.0, creates the database, loads the demo data and opens the live site. Every button, form and upload works and is saved.

Run in GitHub Codespaces
  1. Sign in to GitHub and press Create new codespace.
  2. Wait about 2–3 minutes for the first start; the site opens in a new tab.
  3. If it doesn't, open the PORTS tab and click the globe next to port 8080.

Codespaces is free for personal accounts within GitHub's monthly hours. Stop the codespace when you're done.
